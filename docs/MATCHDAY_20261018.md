# 町田對福岡｜比賽日最後更新

10月18日賽前最後更新：兩隊正式正選、後備及球證已錄入；逐張更新本場選拔狀態。補真也加チュイ大夢10月9日回歸及16日60號公告並建卡；新增17日望月及塚原訪問8則重點。榜更新至17日21:18，天氣為18日13:00日本時間預報。相對最近聯賽，町田換3人、福岡換1人；對比周中兩隊均換10人。未把未開賽0–0當賽果。

## 10月18日最後更新｜正式正選公布後的六個評述重點

正式名單已公布：町田對比周中換10人，今場11名正選在新加坡均最多踢45分鐘；谷、昌子及前寬之沒有上陣。這支持「輪換有效減輕核心負荷」的判斷。真正要觀察的是短時間重新組合後，接應及壓迫能否同步，而不是開場先假定町田疲於奔命。

町田相對最近聯賽換3人，望月、拉維、明本入，中村、仙頭、西村退。小川與恩基同列正選，空中接應與禁區佔位更值得看；相馬會否靠近兩人、明本與望月如何拉闊，要由開場畫面確認，不能只用官網MF／FW分類畫死實際站位。

福岡相對岡山戰只以見木代前田快，維持其餘10人；前田快與橋本均後備。原本最受關注的長擲並非開場必然武器。若下半場前田快入替，要即時看邊線球位置及禁區人數改變；橋本則是連續兩場正式賽事入球後的另一個調節選項。

塚原最新說法把焦點放在防線與中場之間的距離，以及第二名防守者的支援。評述可以看相馬接球時，福岡外側中堅和翼衛誰先出、誰保護身後；如果兩人都被吸到邊線，中路便可能給小川或恩基活動。這是本稿的觀察假設，不是已發生的漏洞。

另一方面，町田應避免把每次進攻都變成同一方向的高波。望月談到耐性與果斷並存，實際可留意：橫傳有沒有移動防守者、傳中前能否先送入內側，或先用小川的牽制讓恩基找到第二落點。福岡若守住前20分鐘，也不代表部署已完成，因為換人會重新改變對位。

昨晚賽後榜：廣島及FC東京同23分，町田少賽一場20分第4；今場勝出便追至23分，但名次仍須按得失球及同日下午賽果判定。福岡7分第17，落後京都1分，僅比降班區的G大阪同分但得失球較好；因此一分亦有實際價值。榜採10月17日21:18完整截點，不混入未完場比分。

## 比賽日天氣｜16:00開波，17:04日落

町田市10月18日13:00日本時間預報：16:00晴22.0°C、濕度53%、南風3米／秒；17:00晴20.9°C、濕度58%、南風2米／秒。兩時段降雨機率0%、雨量0毫米。日落17:04；這是市域預報，並非球場實測。

晴朗、約22°C的下午，比周中新加坡的30°C環境溫和；這只說明比賽環境不同，不等於所有旅途負荷消失。上下半場光線會變，具體陰影、場地方向及草地濕度要看直播畫面。
