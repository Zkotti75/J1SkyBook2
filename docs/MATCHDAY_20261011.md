# 千葉對長崎｜10月11日上午最後更新

10月11日上午最後覆核：兩隊共73張有號碼球員卡與官方名單對照，未發現新增漏卡；更新恩迪奧官方疑似腦震盪記錄、新井個人狀態、10月9日停賽公告、10月10日賽後全榜及比賽日天氣。新增25則近期訪問重點，按四個事件排列並同步人物卡。正選、後備、裁判、恩迪奧醫療許可及逐人累積黃牌臨界仍未確認。

## 新增近期訪問（日期為發布日，賽後事件為比賽日）

### 10月10日｜千葉官方發布：長崎戰賽前

- **小林慶行｜先把戰鬥態度變成結果**：小林要求持續展示戰鬥態度，以比賽結果回報一直支持球隊的人。
- **小林慶行｜第一點、第二點以外也要阻止串連**：長崎的個人能力與J2時一樣突出；要繼續爭第一點及第二點，同時阻止對方傳球組織。
- **鈴木大輔｜佔優時也不能解除警戒**：鈴木提醒長崎前線可在沒有完整拆解防線時，以反擊或傳中射門製造入球，90分鐘都要提防。
- **鈴木大輔｜全隊距離與無球防守**：要維持全隊及防線縱向距離；無球球員也有防守責任，靠支援減少孤立的一對一。
- **姬野誠｜自我要求：強度與入球**：姬野認為自己尚未達到要求，需要提高強度；取得入球和避免輕率失球都是急務。
- **姬野誠｜以勝利回應球迷**：盃賽後球迷答應營造主場氣氛；他希望盡快把操練中的信心化成結果。
  - 短引句：「比起比賽內容，我更想堅持爭取勝利。」；日文：内容よりも、勝ちにこだわっていきたいです。

### 10月9日｜長崎官方發布：千葉戰賽前

- **高木琢也｜艾利臣與千葉的縱向進攻**：高木警惕艾利臣的力量及速度；防線要控制一對一及縱向距離，同時防快翼傳中。
- **高木琢也｜開局與第二點：積極但不要早失球**：先做好第二點、轉換及球際對抗；客場屢早失球，至少力求上半場守住，同時保持主動。
- **新井一耀｜120分鐘後怎樣備戰**：新井表示以恢復體能為先，透過錄影片段及討論整理戰術，再個別恢復身體狀態。
  - 短引句：「未能進行高強度操練。」；日文：強度の高い練習はできませんが
- **新井一耀｜控球要換成射門**：希望增加壓入對方半場的時間，活用長傳及第二點；進攻要多用中路、適時遠射。
- **新井一耀｜不要被福田氣氛吞沒**：認為千葉外援提高個人能力，但瞬間鬆懈仍可利用；客場開局不能被主場氣氛壓倒。
- **新井一耀｜親述身體狀態未接近十足**：季前受傷及季中缺席令狀態仍未接近十足，希望靠比賽逐步提升。這是本人自述，並非缺陣公告。
- **新井一耀｜同為升班球隊，必須爭勝**：盃賽出局後集中聯賽，對同屬升班隊的千葉要爭勝，希望賽後與球迷唱Cantare。

[官方訪問](https://www.v-varen.com/team-comments/249918)

### 10月7日｜天皇盃岡山1–0千葉：賽後

- **小林慶行｜勢均力敵的比賽為何拿不到結果**：小林認為雙方都有機會，千葉未能把握自己的機會；一次死球失守，再次暴露本季問題。
  - 短引句：「被一次死球擊沉了。」；日文：セットプレー一発で沈んだ
- **鈴木大輔｜74分鐘入替踢左閘的任務**：鈴木表示以守穩及把前線推上為任務，與中堅合作爭第一點、拾回第二點，再向前輸送。
- **鈴木大輔｜準備好了，還要提高細節**：他一直準備爭取上陣；失利反映把握機會的重要，需要每天累積細節並提高強度及質素。
- **伊度亞度｜恩迪奧早退後：安井的準備**：伊度亞度讚安井入替後表現出色，證明較少機會的球員也準備充分；球隊仍要把握有限機會。
- **伊度亞度｜個人成績與爭取時間**：他承認本季個人亦未交出結果，會繼續準備，在球場表現並珍惜機會以爭取更多時間。

### 10月7日｜天皇盃清水2–1長崎（加時）：賽後

- **高木琢也｜最後失球：人數夠仍要防到**：高木指出最後傳中及射門質素高，但己方已有足夠人數防守；要把失利教訓落實於準備。
- **高木琢也｜三日內恢復，再處理早失球**：他再次提到客場早段失球，接下來只有三天休息，要恢復狀態備戰千葉。
- **江川湧清｜120分鐘與下一個關鍵戰**：江川希望贏下加時，對近期難保不失感到不甘；盃賽爭取亞洲賽資格的路已斷，要轉向千葉。
- **長谷川元希｜松本天夢推前後的距離**：長谷川認為松本由防中推前，拉近接應距離，對入球有幫助。
- **長谷川元希｜90分鐘強度及後備延續**：他反省失球前丟球與反擊防守，亦指出下半場未能維持強度；換人後也要延續節奏。
- **翁長聖｜問題在開局**：翁長認為開局失球影響全局，球隊回應較遲；之後踢法雖有改善，仍要改善進入比賽。
  - 短引句：「我認為一切都在於比賽開局。」；日文：試合の入りがすべてだったと思います。
- **翁長聖｜四後衛部署的正面部分**：曾準備接球轉身及轉移應對對方四後衛；新部署有正面效果，往後只剩聯賽，要累積積分。
